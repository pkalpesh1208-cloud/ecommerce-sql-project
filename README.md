# E-commerce Data Analysis using SQL and PostgreSQL

## Project Overview
This project focuses on analyzing e-commerce data using SQL and PostgreSQL.

## Project Objective
- Manage customer and product information.
- Analyze order and sales data.
- Retrieve useful information using SQL queries.
- Practice data analysis using PostgreSQL.

## Tools Used
- PostgreSQL
- pgAdmin
- SQL

## Database Tables
- Customers
- Products
- Orders
- Order Items

## SQL Concepts Used
- SELECT statements
- COUNT(), SUM(), and AVG()
- GROUP BY
- ORDER BY
- Aggregate functions
- Data retrieval and analysis

## Key Learnings
- Creating and managing database tables.
- Retrieving data using SQL queries.
- Analyzing product and sales information.
- Understanding e-commerce database structure.

## Project Files
- business_queries.sql - SQL queries for data analysis.
